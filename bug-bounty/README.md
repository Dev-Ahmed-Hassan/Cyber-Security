## Bug Bounty

This directory is reserved for future bug bounty work and is currently in a placeholder state. The subdirectories below exist to establish the intended structure ahead of time, rather than to hold active content.

Active work will begin here once foundational learning through PortSwigger Web Security Academy and live-target practice on OWASP Juice Shop (see `target-practice/`) reaches a sufficient level of depth.

<br>

### Planned Structure

- **`methodology/`** — Testing checklists and systematic approaches to apply when assessing a live program (e.g. `auth-testing-checklist.md`).
- **`practice-reports/`** — Practice writeups formatted as bug bounty reports, organized by vulnerability category, used to build report-writing discipline before submitting to real programs.
- **`public-report-studies/`** — Notes and breakdowns from studying publicly disclosed bug bounty reports, organized by vulnerability category, to learn from real-world findings and reporting style.

<br>

This README will be expanded once active bug bounty work begins.
