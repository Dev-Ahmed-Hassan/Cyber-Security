## Writeups

Structured writeups for guided, lab-based exercises — distinct from `target-practice/`, which covers live, unguided targets. Each writeup documents a specific lab or challenge: the vulnerability, the exploitation steps, and the reasoning behind them.

<br>

### Structure

- **`web-security/portswigger-academy/`** — Writeups for PortSwigger Web Security Academy labs, organized by vulnerability category (e.g. `authentication/`, `api_testing/`). Each lab has its own folder containing a `README.md` (overview and walkthrough), `notes.md` (working notes), `images/` (supporting screenshots), and `scripts/` or `words_list/` where custom tooling or wordlists were used.
- **`reverse-engineering/`** — Writeups for reverse engineering challenges, currently focused on crackmes (`crackmes/`). Each challenge folder follows the same pattern as the PortSwigger writeups, with the addition of the challenge binary itself alongside any keygen or solving scripts.
